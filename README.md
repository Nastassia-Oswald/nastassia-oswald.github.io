# Nastassia Oswald Portfolio

Static site. No build step needed.

## Upload to GitHub in 4 rounds
GitHub's web uploader takes fewer than 100 files at a time, so upload in this order.
Drag the folders themselves (not their contents) so the folder names are kept.

1. The 6 .html files, README.md and the `fonts` folder
2. The `img/cases` folder (36 files)
3. The `img/apps` folder (31 files)
4. The `img/film` folder (32 files)

The images must end up at `img/cases/...`, `img/apps/...` and `img/film/...`.
If GitHub drops a folder at the top level, create the `img` folder first and upload into it.

## Turn on GitHub Pages
Settings, then Pages. Under "Build and deployment" choose "Deploy from a branch", pick `main` and `/ (root)`, then save.
