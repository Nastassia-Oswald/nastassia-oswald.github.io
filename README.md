# Nastassia Oswald Portfolio

Static site. No build step needed: open `index.html` or serve the folder.

## Publish on GitHub Pages
1. Create a repository and upload everything in this folder to the root.
2. Go to Settings, then Pages.
3. Under "Build and deployment", choose "Deploy from a branch", pick `main` and `/ (root)`, then save.
4. The site will be live at `https://<your-username>.github.io/<repo-name>/` after a minute or 2.
